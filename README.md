## News Fusion

A simple news aggregator that pulls articles from multiple sources and presents them as an RSS feed. It also offers a web UI so others can view the data.

> [!CAUTION]  
> This project was **officially deprecated** on October 2, 2025 due to a lack of ongoing interest and development. I have moved the news‑gathering logic and scrapers to private repositories because they contain proprietary code and special scraping techniques that cannot be shared publicly.  
> A new news site is under construction, but its underlying scrapers are no longer open source. Thank you for your support!
